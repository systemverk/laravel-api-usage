# Security Policy

We take security seriously and appreciate responsible disclosure from the community.

## Supported versions

The project currently supports the versions listed in the package metadata and README. Security fixes are typically applied to the currently supported release line and, when needed, may also be backported to the latest maintained branch.

## Reporting a vulnerability

Please do not open a public GitHub issue for a security vulnerability.

Instead, report it privately through GitHub Security Advisories for this repository if available. If private reporting is not possible, contact the maintainer through the repository's private contact channel or the maintainers' preferred secure communication method.

Please include:

- a clear description of the issue
- the affected version(s)
- the reproduction steps or proof of concept
- the impact and risk assessment
- any suggested mitigation or patch

We ask that reports be sent privately so the issue can be investigated and fixed before any public disclosure.

## What to expect

After a report is received, we will:

- acknowledge receipt as quickly as possible
- assess the issue and confirm whether it is valid
- work on a fix in a private or controlled environment when appropriate
- coordinate a release or advisory if the issue is confirmed
- keep the reporter informed as appropriate during triage and resolution

We ask that you give us a reasonable timeframe to investigate before public disclosure.

## Responsible disclosure guidelines

Please:

- avoid exploiting the issue beyond the minimum needed to validate it
- do not access or modify data that is not your own
- do not disclose the issue publicly until we have had time to address it
- do not use the issue for spam, abuse, or unrelated activity

## Scope

This policy applies to vulnerabilities in the package itself, including insecure defaults, unsafe assumptions, validation issues, and data-handling mistakes that affect the intended security model of the package.

If you are unsure whether something qualifies as a vulnerability, please reach out before publishing details.

Thank you for helping keep this package safe for users.
